# IQRA Career Roadmap

Student guidance platform for **Iqra University M9 Campus**.

The React app lives in the **`ICT project`** folder.

## Commands (from this folder)

```bash
npm install    # installs dependencies (workspace: ICT project)
npm run dev    # start dev server → http://localhost:5173
npm run build  # production build
npm run preview
```

The app source is in **`ICT project/`**. You can also run commands there directly:

```bash
cd "ICT project"
npm run dev
```

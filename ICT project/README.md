# Iqra University M9 — Student Admission Guide

Premium frontend portal for new admission students at **Iqra University M9 Campus**.

## Features

- Landing hero with animations
- Interactive degree & specialization selection
- 8-semester roadmap timeline
- Career paths, skills, and industry demand
- Pakistan salary insights (PKR)
- Internship & freelancing guidance
- FAQ and motivation CTA

## Stack

- React 19 + Vite
- Tailwind CSS v4
- Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Note

This is a **frontend-only** educational demo. Confirm official program details with the Iqra University admissions office.
